▶ Module 1 · 15 min

Qu'est-ce qu'une macro ?

Une macro, c'est un petit programme qui exécute automatiquement une suite d'actions à la place de l'utilisateur. Une fois écrite, elle se lance d'un seul clic.

Le problème : les tâches répétitives

Imagine que tu doives mettre en gras + remplir en jaune + centrer le contenu de 50 cellules. À la main, ça prend des minutes. Avec une macro, c'est instantané. La macro fait à ta place ce que tu lui as appris à faire.

★Ce qu'il faut comprendre

  • Chaque instruction dit une action précise au tableur.
  • Quand on l'exécute, les instructions sont jouées de haut en bas, dans l'ordre.
  • On peut la relancer autant de fois qu'on veut.
▶ Module 2 · 15 min

Enregistrer une macro

Bonne nouvelle : tu n'as pas besoin de tout coder à la main. Excel possède un enregistreur de macros qui transforme tes clics en code VBA automatiquement.

Le principe

  1. Tu cliques sur « Enregistrer une macro » dans l'onglet Développeur.
  2. Tu fais les actions que tu veux automatiser (saisir, mettre en forme, etc.).
  3. Tu cliques sur « Arrêter l'enregistrement ».
  4. Excel a écrit le code VBA correspondant à tes actions. Tu peux le lire, le modifier, le rejouer.
⚠Important

L'enregistreur est utile pour débuter, mais il produit souvent du code verbeux (long et un peu maladroit). Apprendre à lire et à écrire toi-même le code VBA permet d'avoir des macros bien plus courtes et puissantes.

Simulation : enregistre tes actions

Dans ce mini-environnement, clique sur ● Enregistrer, fais quelques actions (saisir une valeur dans une cellule, par exemple), puis clique sur ■ Arrêter. Le code VBA correspondant apparaît dans la zone de droite.

▶ Module 3 · 40 min

Lire et écrire du code VBA

Une fois enregistrée, ta macro existe sous forme de code VBA. Apprenons à le lire et à l'écrire toi-même.

La structure d'une macro

Toute macro commence par Sub et se termine par End Sub :

Sub MaPremiereMacro()
    ' Ici, les instructions de la macro
    Range("A1").Value = "Bonjour"
End Sub
  • Sub MaPremiereMacro() : déclare une macro qui s'appelle « MaPremiereMacro ».
  • End Sub : marque la fin de la macro.
  • Tout ce qui est entre les deux est exécuté quand on lance la macro.
  • Une ligne qui commence par ' (apostrophe) est un commentaire — ignoré par l'ordinateur, juste une note pour toi.

Écrire dans une cellule

Pour écrire dans la cellule A1, on utilise :

Range("A1").Value = "Bonjour"
Range("B2").Value = 42
Cells(3, 1).Value = "Ligne 3, colonne 1"
  • Range("A1") : on désigne la cellule par sa référence (lettre + chiffre).
  • .Value : on accède à la valeur de la cellule.
  • = : on lui donne une nouvelle valeur.
  • Cells(3, 1) : autre façon — la cellule à la ligne 3, colonne 1 (= A3). Utile avec des variables.

Mettre en forme

Range("A1").Font.Bold = True
Range("A1").Interior.Color = RGB(255, 255, 0)
  • .Font.Bold = True : met le texte en gras.
  • .Interior.Color = RGB(R, G, B) : change la couleur de fond. RGB(255,255,0) = jaune.

▶ Module 4 · 40 min

Les boucles — répéter sans s'épuiser

Pour remplir 10, 100 ou 1000 cellules, on ne va pas écrire 1000 lignes de code. On utilise une boucle.

La boucle For ... Next

Cette boucle répète un bloc de code plusieurs fois en faisant varier un compteur : 

For i = 1 To 10
    Cells(i, 1).Value = i
Next i
▸Décodage de cette boucle
  • For i = 1 To 10 : démarre une boucle où i va prendre les valeurs 1, 2, 3, …, 10.
  • Cells(i, 1).Value = i : à chaque tour, écrit la valeur de i dans la cellule de la ligne i, colonne 1.
  • Next i : ferme la boucle, on revient en haut avec la valeur suivante.

Résultat : les cellules A1 à A10 contiennent 1, 2, 3, … 10.

Démo : la boucle au travail

Modifie le nombre 10 par 20, 50 ou 100. Exécute et observe :

Variables

Tu peux utiliser des variables pour stocker des valeurs et les réutiliser. On les déclare avec Dim : 

Dim n As Integer
n = 5
For i = 1 To n
    Cells(i, 1).Value = i * 2
Next i

Cette macro remplit A1 à A5 avec 2, 4, 6, 8, 10.

▶ Module 5 · 30 min

Conditions et interactions

Une vraie macro doit pouvoir réagir selon les situations. Le mot-clé If permet de faire un choix.

La structure If ... Then ... Else ... End If

If x > 10 Then
    Cells(1, 1).Value = "Grand"
Else
    Cells(1, 1).Value = "Petit"
End If
  • If x > 10 Then : si la valeur de x est plus grande que 10…
  • … on exécute la première instruction.
  • Else : sinon, on exécute la seconde.
  • End If : ferme la condition.

Exercice 10 · 8 min

Le décompte

À faire : Remplis les cellules A1 à A10 avec un décompte : 10, 9, 8, 7, … 1.

Deux pistes possibles :

  • Utiliser For i = 10 To 1 Step -1 avec un compteur de ligne séparé.
  • Ou utiliser une boucle classique For i = 1 To 10 et écrire Cells(i, 1).Value = 11 - i.
Exercice 11 · 14 min

Le cadre coloré

À faire : Dans une grille 6 × 6, colore en bleu RGB(100, 150, 255) uniquement le contour du rectangle (les cellules qui sont sur la première ligne, la dernière ligne, la première colonne ou la dernière colonne). L'intérieur reste blanc.

Indice : utilise Or pour combiner plusieurs conditions :

If i = 1 Or i = 6 Or j = 1 Or j = 6 Then
    Cells(i, j).Interior.Color = RGB(100, 150, 255)
End If
